01

自主项目 / 组合项目

创投情报与多渠道发布工作台

定位
把“创投”和“小红书 MCP”合并为一条作品线：从公开创投资讯进入系统，到结构化抽取、内容审核、图卡生成和发布执行。
实现
使用 Playwright、MySQL 和 LLM 构建增量采集与抽取流程，生成固定尺寸图卡、文案和 manifest；再通过带 Token 校验、dry-run 和账号健康检查的 sidecar 接入小红书 MCP。发布流水线保留人工确认，并用 LangGraph 处理搜索重试、质量闸门和异常分支。
边界
情报工作台与发布服务独立部署；实际发布默认需要人工确认。MCP 浏览器能力基于开源 xiaohongshu-mcp 扩展，并增加 CloakBrowser 适配和 Windows 私有部署包。

02

自主开源项目

Code Archaeology Skill

定位
帮助接手旧模块的工程师回答“这段代码为什么变成今天这样”，把零散 Git 历史整理成可核验的演化报告。
实现
实现本地 Git 证据采集器，支持文件、目录、glob、模块名和符号查询，整理 rename、revert、blame 存活度与提交评分；可选补充 Python AST 差异、GitHub/GitLab 协作记录，并将证据包渲染为离线 HTML 时间线。
边界
采集器只负责排序和组织证据，最终结论仍要求 Agent 阅读关键 diff。默认不访问远端，也不根据提交数量推断所有权或作者动机。

04

自主原型

热点线索台与 IP 选题库

定位
为个人 IP 孵化建立一个可持续更新的热点入口，集中查看不同来源的主题、热度变化和来源健康状态。
实现
从 NewsNow 公共源定时采集热点，使用唯一键增量入库，只在排名、热度或摘要变化时写快照；通过 MySQL FULLTEXT ngram 支持中文检索，并提供精简的 AI 搜索接口和同步运行状态。
边界
当前是可运行原型，数据源依赖公共 NewsNow 服务；正式使用需要自建数据源并补充更完整的采集监控、权限与内容合规策略。
